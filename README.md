# Открытка для Оли

Небольшая интерактивная mobile-first открытка ко дню рождения. Сделана на обычных HTML, CSS и JavaScript — без сборки, зависимостей и backend.

## Запуск локально

Откройте `index.html` в браузере. Для этой статической страницы сервер разработки не требуется.

## Публикация через GitHub Pages

В репозитории откройте **Settings → Pages** и выберите **GitHub Actions** в качестве источника сборки. После push в `main` workflow `.github/workflows/deploy.yml` автоматически опубликует сайт.

Ожидаемый адрес:

`https://starkelessar.github.io/olga-birthday/`

Публикация считается завершённой только после успешного workflow и проверки адреса.

## Структура

- `index.html` — разметка и текст поздравления.
- `styles.css` — адаптивный дизайн и анимации.
- `script.js` — интерактивность и конфетти.
- `.github/workflows/deploy.yml` — автоматический деплой в GitHub Pages.

## Доступность

Есть управление кнопками с клавиатуры, видимый focus, статус для screen reader и поддержка `prefers-reduced-motion`.
